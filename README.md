# Agência do Zero — LP GAABTUR

Landing page de vendas do treinamento "Agência do Zero", na identidade da GAABTUR.
Arquivo único: `index.html` (abre direto no navegador).

## Configuração

No início do `<script>` do `index.html` há um bloco `CONFIG`:

- `checkoutUrl` — link do checkout. Vazio = o botão do bilhete abre o WhatsApp com o nome digitado.
- `whatsapp` — número com DDI + DDD, só dígitos.
- `whatsMsg` — mensagem padrão dos botões de WhatsApp.
- `fotoGabi` — caminho da foto da Gabi (ex.: `gabi.jpg`, ao lado do `index.html`). Vazio = monograma.

> Os depoimentos da seção "Quem seguiu, embarcou" precisam ser substituídos por depoimentos reais de alunos antes de divulgar.
